RV32IMC Zicsr · Zifencei 5-stage pipeline SystemVerilog Wishbone B4 2.62 CoreMark/MHz Machine-mode GPL-3.0
Bir pipeline aşamasına veya hazard unit banner'ına tıkla ve detaylarını gör.
Cache hiyerarşisi: L1 I-Cache + L1 D-Cache (non-blocking, MSHR) → Memory Arbiter → L2 Unified Cache (opsiyonel, USE_L2_CACHE=1) → Wishbone B4 → RAM / Peripheral. D-Cache Prefetcher: D-cache miss olduğunda bir sonraki cache satırını önceden çeker (memory.sv inline, yalnızca RAM bölgesi). Stride prefetcher (stride_prefetcher.sv) de mevcuttur ancak şu an devre dışı; ilerleyen versiyonlarda etkinleştirilmesi planlanmaktadır. I-Cache Prefetcher: next_line_prefetcher.sv + prefetcher_wrapper.sv instruction fetch yolunda çalışır.
SoC: Level-V Core → Wishbone B4 Interconnect → CLINT + BRAM + 10 Peripheral. PLIC 16 harici IRQ kaynağını yönetir ve meip sinyali ile core'u interrupt eder. VGA text-mode çevre birimi 0x2000_D000 adresinde; grafik framebuffer 0x2010_0000'de yer alır.
Tournament predictor: GShare + Bimodal → Choice PHT hangisinin daha doğru olduğunu seçer. BTB (256) hedef adresi, IBTC (32) indirect branch'ları, RAS (16) return adreslerini önbellekler. Loop predictor sabit iterasyonlu döngüleri tanır. Tüm boyutlar level_param_profile.svh üzerinden yapılandırılır (Full / Minimal / OpenLane profilleri).
Memory haritası: 0x0000_0000 Debug → 0x1000_0000 BootROM → 0x2000_0000 Peripheral → 0x3000_0000 CLINT → 0x4000_0000 ExtMem → 0x8000_0000 RAM (reset vector). VGA metin tamponu 0x2000_D000, grafik framebuffer 0x2010_0000 adresinde. Tüm parametreler level_param.sv'de merkezi olarak tanımlı.
